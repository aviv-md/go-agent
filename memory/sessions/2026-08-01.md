## Milestone: Task 3 — model types shape (flat Response)

**Decided**

- `Model.Prompt([]Message) (Response, error)` — package `model`, type `Model` ok (à la `context.Context`).
- `Message`: `Role` + `Content` only (no `Time` on the I/O type).
- Roles: user / assistant / system / tool (tool = transcript observations later).
- `Response` is **flat**: `Content` + `ToolCalls` (stub `[]any`). Not an embedded `Message`.
- Agent owns converting a response into history: `Message{Role: assistant, Content: resp.Content}` (+ handle tool calls when Task 7/9).
- Tool **calls** live in `model`; tool **execution** stays in `tools`. Stop rule remains: no tool calls ⇒ final answer (no `IsFinal`).
