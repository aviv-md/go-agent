## Milestone: Task 4 design — ReAct loop ownership

**Decided**

- Task 4 proven with a **fake/test `Model`** — do not fold Task 5 (provider) or Task 8 (tools) into it.
- `Run(ctx, input) (string, error)` — `ctx` is required (cancel/timeout), not YAGNI.
- Stop rule: **empty `ToolCalls`** ⇒ that `Content` is the final answer (no `is_final`).
- Budget: max iterations / max `Prompt` laps — backstop alongside empty tool calls.
- Teaching model: Thought = assistant **text** riding with Action; Action = tool calls; Observation = tool result appended later. Provider “reasoning” knobs ≠ ReAct Thought.
- Control flow: seed user → lap `Prompt` → empty tools? done : (later) append + continue.

**Open**

- Nil `Model` check in `NewAgent`?
- Whether budget error should carry last `Content` (custom error) or be a plain error for v1.

- `NewAgent(m model.Model, maxIterations uint8)`; `0` → warn + default (10).
- `Model` field is `model.Model` (interface).
- Agent returned / used as **pointer** — expect state later; avoid copy footguns.
- `Model.Prompt(ctx, …)` widened; `Run(ctx, input) (string, error)`.
- Budget exhausted ⇒ **hard error** (no soft “1 lap left” nudge for now).
